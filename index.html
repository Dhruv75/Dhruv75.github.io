How I work

The same four steps, whether it's a payments ledger or an LLM agent.

01

Constrain

Write down what must never happen: a negative balance, a write query, a made-up column.

02

Build

Pick the simplest design that makes those failures impossible, not just unlikely.

03

Prove

Attack it with tests: parallel requests, injection attempts, golden sets.

04

Ship

Gate it in CI so the proof keeps running after I've moved on.
